# thicket-mobile

Expo / React Native app for Thicket. Talks to
[thicket-api](https://github.com/mtyates-coderabbit/thicket-api) through Apollo Client.

## Layout

- `App.tsx` — root component with a simple tab bar (Shop, Orders).
- `src/screens/` — Shop, Orders, and Receipt screens.
- `src/components/` — shared UI.
- `src/graphql/` — operations and fragments, one per file.
- `src/gql/graphql.ts` — generated by `npm run codegen`. Never edit by hand.
- `schema/thicket-api.graphql` — vendored API schema, refreshed with `npm run schema:pull`.
- `src/lib/` — helpers that interpret API values (status theme, money, analytics, payment).

## Conventions

- After changing any `.graphql` file, run `npm run codegen` and commit the generated output.
- Released builds stay in use for weeks. Code must tolerate API enum values it does not
  know about and must not assume a field is non-null unless the schema says so.
- API amounts are USD dollars. Use `formatPrice` for display and `toCents` for analytics.
- Only depend on API fields that exist on thicket-api `main`.
- Use `npx expo install <package>` to add dependencies so versions match the Expo SDK.
